#RF

- [ ] Usuário deve poder criar transações
- [ ] Usuário deve poder acessar informações da própria conta
- [ ] Usuário deve poder acessar histórico de transações
- [ ] Usuário deve poder visualizar detalhes de transações especificas

#RN

- [ ] Transaçôes podem depositar ou sacar valores
- [ ] Deve ser possível identificar o usuário entre as requisições
- [ ] Usuário só deve poder visualizar as próprias transações
